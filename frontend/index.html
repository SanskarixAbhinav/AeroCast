System Architecture & Scope Transparency

AeroCast / WeatherGPT is engineered for absolute technical honesty and judge-proof rigor. Below is the explicit verification matrix detailing what is live and operational, what is simulated for demonstration, and what is on the roadmap.

Real & Operational in MVP

  • Open-Meteo Live API: Hyperlocal real-time weather & 7-day forecast (temperature, humidity, precipitation sum/prob, wind speed/gusts, FAO-56 evapotranspiration ET0).
  • Open-Meteo Marine API: Real-time wave height, wave period, wave direction, and swell height for coastal locations with deterministic safety checks for coastal fishing and small craft.
  • NWP Model Comparison: Real-time multi-model ensemble comparison contrasting NOAA GFS Seamless vs ECMWF IFS for transparent forecast consensus analysis.
  • Historical Archive: ERA5 reanalysis data spanning 1940 to present, rendered with a hand-rolled inline SVG climate trend chart.
  • Google Gemini 3.8 Flash: Dual-turn architecture: (1) structured JSON intent parsing, and (2) multilingual narration across 6 Indian languages (en, hi, bn, ta, te, mr).
  • Deterministic Rule Engines: Zero-hallucination agricultural decisions for spraying windows, irrigation need, and harvest suitability.
  • Anti-Hallucination Numbers Guard: Strict regex/numerical verification rejecting 100% of LLM replies containing ungrounded numbers.
  • Response Latency Telemetry: Actual measured server response time (meta.latency_ms) displayed under every answer.
  • Installable PWA: Web App Manifest and Service Worker static shell caching for offline loading.

Simulated Demo Features

  • Active Cyclone Bulletin: Seeded emergency bulletin demonstration allowing evaluation of coastal storm surge advisories and evacuation protocols without waiting for a real-world disaster. Explicitly watermarked [SIMULATED] in data cards and text.
  • Regional Disaster Overview: High-level city-granularity demonstration visualizing simultaneous multi-hub alert statuses across India on Leaflet.

Explicit Roadmap (Out of Scope)

  • WRF Regional Downscaling: Running proprietary 3km Weather Research and Forecasting (WRF) numerical models requires dedicated GPU/HPC cluster infrastructure.
  • Official IMD / NDMA CAP Feeds: Production ingestion of statutory Common Alerting Protocol (CAP) RSS/XML feeds requires statutory agency clearance and credentials.
  • WMO WIS 2.0 / MQTT Ingestion: Global high-frequency meteorological telemetry pub-sub brokers are scheduled for Phase 2 scaling.
  • Kubernetes Autoscaling: Currently hosted on serverless Supabase Edge Functions (Deno); k8s orchestration is planned for high-concurrency national rollouts.
  • Native Mobile Binaries: Delivered as an installable Progressive Web App (PWA); native APKs/IPAs with background push are on the future roadmap.
  • Aviation Weather Briefing: Intentionally excluded because Open-Meteo does not provide certified ICAO METAR/TAF ceiling and runway visibility data; synthesizing aviation guidance without certified aviation sensors would be unsafe.
